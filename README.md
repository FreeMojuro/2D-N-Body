# 2D N-Body Simulation

## Controls

| Key / Action | Function |
| :--- | :--- |
| **`Space`** | Pause / Resume simulation |
| **`Q`** / **`E`** | Decrease / Increase simulation speed |
| **`Left Click`** | Add a new body |
| **`Delete`** | Remove the last added body |
| **`Shift + Delete`** | Fast delete |
| **`R`** | Reset simulation |
| **`Arrow Keys`** | Pan / Move camera |
| **`Scroll Wheel`** | Zoom in / Zoom out |
| **`B`** | Enable / Disable Black Hole mode |
| **`Numbers 1-4`** | Change preset |
